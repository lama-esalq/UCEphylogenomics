# UCE Assembly - PHYLUCE Processing Pipeline

This workflow implements a modular pipeline for UCE (Ultraconserved Elements) phylogenomics using Snakemake and PHYLUCE. The current version performs read quality control, read cleaning, de novo assembly, assembly quality control, UCE probe matching, locus extraction, FASTA organization, and locus-level quality control.

The workflow is designed to progressively reproduce and automate the main steps of the PHYLUCE workflow while providing a reproducible Snakemake framework in which parameters, input files, software environments, and computational resources are controlled through configuration files.

**This pipeline is still a work in progress. Some downstream PHYLUCE steps are not yet implemented, so use it with caution and carefully inspect intermediate results.**

## Workflow Overview

The current implementation includes:

### 1. Quality Control

Raw sequencing reads are assessed before and after cleaning.

* Raw reads are evaluated with **FastQC**.
* Adapter removal and quality filtering are performed with **fastp**.
* Paired reads retained after cleaning are written as separate R1 and R2 files.
* Reads that lose their mate during cleaning are retained as single reads.
* Cleaned reads are evaluated again with **FastQC**.
* **MultiQC** is used to summarize FastQC and fastp results across samples.
* QC outputs are stored under `results/00-qc/`.

### 2. De Novo Assembly and QC

Cleaned reads are assembled independently for each sample using **SPAdes through the PHYLUCE framework**.

* An individual PHYLUCE assembly configuration file is generated for each sample.
* `phyluce_assembly_assemblo_spades` is used for the assembly.
* Assembly parameters such as threads and memory are controlled through `config.yaml`.
* Assembly results are stored under `results/01-assembly/`.
* Basic assembly statistics are generated using `phyluce_assembly_get_fasta_lengths`. The resulting summary is stored in `results/01-assembly/qc/contig_lengths.csv`.

### 3. Matching Contigs to UCE Probes

After assembly, the assembled contigs are compared to the expected set of probes in order to identify UCE regions.

* Assembled contigs are searched against the selected UCE probe set using `phyluce_assembly_match_contigs_to_probes`.
* The probe sequences and matching parameters are specified in `config.yaml`.
* The matching results are summarized using `phyluce_assembly_get_match_counts`

### 4. Generating UCE Locus FASTA Files

According to the match results, loci files are created for each sample.

* UCE FASTA files are generated using `phyluce_assembly_get_fastas_from_match_counts`
* The taxon set used for this step is defined in the configuration file. The value of `taxon-set_name` is also used as the dataset identifier in the output filenames.
* The combined UCE FASTA generated by PHYLUCE is separated into individual FASTA files using `phyluce_assembly_explode_get_fastas_file`.

### 5. UCE FASTA Quality Control

The files are organized by taxon/sample, following the PHYLUCE workflow structure. Because the number of samples successfully represented in the FASTA depends on the quality of the assemblies and probe matching, the pipeline uses a Snakemake checkpoint to handle the dynamically generated FASTA files.

The individual exploded FASTA files are evaluated using `phyluce_assembly_get_fasta_lengths`, which produces a summary of contig/locus sequence lengths for the UCE sequences recovered from the assemblies.

## Configuration

Pipeline settings are controlled through `config/config.yaml`.

A simplified example configuration is:

```yaml
samples: 'config/samples.csv'

threads:
  fastp: 4
  assembly: 6

# Memory for assembly is specified in Gb
memory:
  assembly: 4

params:
  fastp: "--cut_mean_quality 24 --cut_tail --cut_front --trim_poly_g --detect_adapter_for_pe --dont_eval_duplication --length_required 50"

env:
  qc: "../../envs/qc.yml"
  phyluce: "../../envs/phyluce-1.7.3-py36-macOS-conda.yml"

match_contigs:
  probes: "config/Tetrapods-UCE-5Kv1.fasta"
  taxon-set_file: "config/taxon-set.conf"
  taxon-set_name: "all"
  get_match_counts_params: "--incomplete-matrix"
```

The `match_contigs` section controls the UCE probe matching and locus extraction steps.

* `probes`: FASTA file containing the UCE probe sequences.
* `taxon-set_file`: PHYLUCE taxon-set configuration file.
* `taxon-set_name`: name of the taxon group to process. This value is also used as the dataset identifier in output filenames.
* `get_match_counts_params`: additional parameters passed to `phyluce_assembly_get_match_counts`.

## Sample Metadata

Sample metadata are provided as a CSV file.

The current format is:

```csv
sample,r1,r2,layout
Sample1,data/Sample1_R1.fastq.gz,data/Sample1_R2.fastq.gz,PE
Sample2,data/Sample2_R1.fastq.gz,data/Sample2_R2.fastq.gz,PE
```

The `sample` column defines the sample identifier used throughout the workflow.

The `r1` and `r2` columns contain the paths to the raw sequencing reads.

The `layout` column specifies the library layout.

**Note:** Support for single-end raw sequencing libraries is being developed. The current implementation is primarily configured for paired-end input data.

## Conda Environments

Software dependencies are managed through Conda environments. The workflow uses separate environments for quality-control tools and PHYLUCE-related tools.

The environments can be automatically created by Snakemake using the `--use-conda` option.

For example:

```bash
snakemake --use-conda --cores 16
```

Alternatively, the environments can be created manually using the provided environment files:

```bash
conda env create -f envs/qc.yml
conda env create -f envs/phyluce-1.7.3-py36-macOS-conda.yml
```

If manually created environments are used, the corresponding entries in `config.yaml` should be changed to the names of the installed environments.

For example:

```yaml
env:
  qc: "qc"
  phyluce: "phyluce-1.7.3"
```

When using Snakemake-managed environments, the paths to the environment YAML files should be specified in the configuration.

## Running the Pipeline

After configuring the input files, parameters, probe sequences, and taxon set, the complete workflow can be executed with:

```bash
snakemake --use-conda --cores 16
```

A dry run is highly recommended before running the workflow, inspecting the commands that will be executed:

```bash
snakemake -np
```

Individual stages can also be executed using Snakemake targets or rules. For example, to run only the raw-read FastQC step:

```bash
snakemake --use-conda --cores 2 --until fastqc_raw
```

## Output Structure

The current workflow follows a directory structure inspired by the PHYLUCE tutorial, while separating the major processing stages:

```text
config/
├── config.yaml
├── samples.csv
├── taxon-set.conf
└── Tetrapods-UCE-5Kv1.fasta
envs/
├── qc.yml
└── phyluce-1.7.3-py36-macOS-conda.yml
logs/
├── fastp/
├── fastqc/
├── multiqc/
├── assembly/
└── phyluce/
results/
├── 00-qc/
│   ├── fastp/
│   ├── fastqc/
│   │   ├── raw/
│   │   └── cleaned/
│   └── multiqc/
│
├── 01-assembly/
│   ├── Sample1.conf
│   ├── Sample1_spades/
│   │   └── contigs.fasta
│   ├── Sample2.conf
│   ├── Sample2_spades/
│   │   └── contigs.fasta
│   └── qc/
│       └── contig_lengths.csv
│
├── 03-match_contigs/
│   ├── Sample1.contigs.lastz
│   ├── Sample2.contigs.lastz
│   ├── probe.matches.sqlite
│   └── all.probe.matches.conf
│
└── 04-uce-fastas/
    ├── all.probe.matches.fasta
    ├── all.probe.matches.incomplete
    ├── all.contig_lengths.csv
    └── exploded/
        └── all/
            ├── UCE001.unaligned.fasta
            ├── UCE002.unaligned.fasta
            └── ...
```

The exact number of files in the `exploded/` directory depends on the UCE loci successfully recovered from the input assemblies.

## Current Workflow

The current workflow can be summarized as:

```text
Raw FASTQ
    │
    ├── FastQC
    │
    ├── fastp
    │
    ├── FastQC
    │
    └── MultiQC
          │
          ▼
   Clean FASTQ files
          │
          ▼
   SPAdes assembly
   (one sample at a time)
          │
          ▼
   Assembly QC
          │
          ▼
   Contigs
          │
          ▼
   Match contigs to UCE probes
          │
          ▼
   Match counts / taxon set
          │
          ▼
   UCE FASTA extraction
          │
          ▼
   Explode FASTA by taxon
          │
          ▼
   UCE FASTA QC
```
